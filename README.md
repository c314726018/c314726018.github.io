# 今日金价 · 实时黄金行情站（SGE）

一个**零依赖、零服务器成本**的贵金属行情网站，部署在 **GitHub Pages**（免费），数据每小时自动刷新。

## 功能（v2）
- 📊 **实时行情表**：上海黄金交易所 Au99.99 / Au99.95 / iAu99.99 / Ag99.99 / Pt99.95 / Pd99.95 最新价、今开、最高、最低。
- 🌍 **国际对比**：国际现货黄金 XAU/USD、美元兑人民币 USD/CNY，以及 **国内溢价%**（SGE 较国际折算的价差）。
- 📈 **图表**：主力合约分时走势、K线（分时聚合）、多品种日内归一化对比。
- 🔔 **价格提醒**：设「价格 高于/低于 某值」即通知（浏览器通知 + 本地存储）；每 60s 拉取最新数据自动评估。
- 📱 **响应式 + 暗色模式**：手机 / 平板 / 桌面自适应，支持暗色主题（跟随系统或手动切换）。
- 🔍 **SEO + 科普**：标题/描述/关键词/JSON-LD，含「今日金价是多少」等 FAQ 与黄金科普，利于百度/搜索收录。
- 💡 **广告位占位**：页面内置顶部/内容中插/页脚广告位，粘贴百度联盟 / AdSense 代码即可变现。

## 文件结构
- `fetch.py` — 抓取 SGE 行情 + 国际金价 + 汇率，计算国内溢价，写 `data.json`（带兜底，永不空白）
- `build.py` — 读 `data.json` 渲染 `docs/index.html` 与 `docs/data.json`（自托管 Chart.js + K线插件）
- `docs/index.html` / `docs/app.js` / `docs/vendor/` — 站点前端
- `.github/workflows/update.yml` — 每小时自动抓取+构建+提交+部署

## 变现入口
| 方式 | 怎么做 |
|---|---|
| 展示广告 | 百度联盟 / AdSense 代码贴进 `docs/index.html` 的广告位（标注 `ad-slot` 处） |
| 开户返佣 | 对接**持牌机构**贵金属/银行开户链接，放页脚广告位（务必合规） |
| 私域/订阅 | `docs/app.js` 中 `FORM_ENDPOINT` 填入邮件服务（如 Formspree）即可启用金价异动邮件订阅 |

## 合规红线
- 仅做**行情展示聚合**，不提供投资建议、不代客理财。
- 页面已标注「仅供参考，不构成投资建议」。
- 开户返佣必须对接**持牌机构**；外盘/黑平台/客损分成 = 违法，严禁。
